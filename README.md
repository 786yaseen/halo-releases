# Halo for Windows: downloads

Installers for **Halo**, the desktop assistant for Windows 11.

- **Get Halo:** download `Halo-Setup-<version>.exe` from the [latest release](https://github.com/786yaseen/halo-releases/releases/latest), or use the button on [halo-assistant.web.app](https://halo-assistant.web.app).
- **Updates:** an installed Halo updates itself. It checks a signed manifest on halo-assistant.web.app and installs only an update whose signature matches Halo's release key.
- **Privacy:** [halo-assistant.web.app/privacy.html](https://halo-assistant.web.app/privacy.html)

This repository holds only the installers. Halo's source code is not published here.
